# Examples

Run `python demo.py` from the project root. Generated artifacts for each sample
patient are written here under `output/`:

- `<patient>_timeline.json`  structured, code-mapped events
- `<patient>_timeline.csv`   the same as a flat table
- `<patient>_timeline.html`  interactive Plotly trajectory
- `<patient>_explanation.html`  risk score + per-event attribution + SHAP
